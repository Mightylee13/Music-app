# Lenzo Music

Music-only web app and API. The player uses the existing uploaded YouTube Music scraper and its `yt-dlp`/`ffmpeg` audio pipeline. It does not use the shared Theresa/AI resolver or the WhatsApp bot.

## Run locally

Requirements: Node.js 22+, pnpm 10+, Python 3, `yt-dlp`, and `ffmpeg`.
If those tools are not already on `PATH`, set `YT_DLP_PATH` and `FFMPEG_PATH` to their executable paths.

```sh
cp .env.example .env
pnpm install
PORT=10000 BASE_PATH=/ NODE_ENV=production pnpm build
pnpm start
```

Open `http://localhost:10000`. The server exposes `/api/healthz` for health checks.

## Deploy on Render

Create a Blueprint from this repository and use `render.yaml`, or create a Docker web service using the included `Dockerfile`. Render will request these values without storing them in the repository:

- `LENZO_MUSIC_ADMIN_PASSWORD` — password for the private admin page.
- `SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET` — optional Spotify playlist import credentials.
- `SESSION_SECRET` — generated by the Blueprint.

The app's audio and HLS caches are temporary; playlists are stored in the listener's browser. The service does not need a persistent disk for those features.
